# 👑 Beauty Queen - ระบบร้านเสริมสวย

โปรแกรมจองคิวและจัดการร้านเสริมสวย เขียนด้วย Python (Tkinter) + SQLite 

## ทำอะไรได้บ้าง
- หน้าร้านลูกค้า: ดูบริการและราคา, จองคิว 4 ขั้นตอน, เช็ก/ยกเลิกการจองด้วยเบอร์โทร
- โหมดเจ้าของร้าน (รหัส PIN เริ่มต้น 1234): แดชบอร์ด, นัดหมาย, ลูกค้า, บริการ, พนักงาน

## วิธีรัน
python salon_app.py

## วิธีติดตั้งแบบโปรแกรม
ไปที่แท็บ Releases ดาวน์โหลด BeautyQueen_Setup.exe แล้วดับเบิลคลิก
(ถ้า Windows เตือน ให้กด "ข้อมูลเพิ่มเติม" แล้ว "เรียกใช้อยู่ดี")
